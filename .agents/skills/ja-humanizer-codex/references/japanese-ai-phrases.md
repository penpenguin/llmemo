# 日本語AI臭 表現カタログ

この一覧は、一括禁止リストではありません。文脈によっては自然に使えます。ただし、同じ文章内で複数出るとAI臭が強まります。

## 1. まとめ・導入の定型句

注意したい表現：

- 「この記事では〜について解説します」
- 「〜について詳しく見ていきましょう」
- 「結論から言うと」
- 「重要なのは以下の3点です」
- 「まず、〜。次に、〜。最後に、〜」
- 「ここでは、〜を紹介します」

自然化の方向：

- 読者が気になっている場面から入る。
- 問いから入る。
- 具体的な違和感から入る。
- 前置きなしで本題に入る。

例：

```text
Before: この記事では、AIライティングのメリットについて解説します。
After: AIで文章を書くと、速くなる一方で「誰が書いても同じ」に見える瞬間があります。
```

## 2. 抽象的な価値語

注意したい表現：

- 「価値を提供する」
- 「ユーザー体験を向上させる」
- 「課題解決につながる」
- 「業務効率化を実現する」
- 「多様なニーズに対応する」
- 「最適なソリューション」
- 「持続可能な成長」
- 「新たな可能性を切り拓く」

自然化の方向：

- 誰の、どんな手間が減るのか。
- 何を判断しやすくなるのか。
- どの作業が短くなるのか。
- 何を選びやすくなるのか。

例：

```text
Before: 業務効率化を実現します。
After: 確認待ちや手戻りを減らします。
```

## 3. 意義づけが大きい表現

注意したい表現：

- 「〜において重要な役割を果たします」
- 「〜の観点から非常に重要です」
- 「〜に大きく貢献します」
- 「今後ますます重要になるでしょう」
- 「今後の展開が注目されます」
- 「〜の可能性を秘めています」

自然化の方向：

- 何がどう重要なのかを書く。
- 重要である理由を1つに絞る。
- 断定できないなら、残る論点を書く。

例：

```text
Before: 今後の展開が注目されます。
After: まず見るべきなのは、導入後に現場の手戻りが本当に減るかどうかです。
```

## 4. 過剰な接続詞

注意したい表現：

- 「また」
- 「さらに」
- 「一方で」
- 「加えて」
- 「このように」
- 「これにより」
- 「そのため」
- 「したがって」
- 「なお」

自然化の方向：

- 接続詞を消しても意味が通るなら消す。
- 前文の言葉を受ける。
- 因果が弱いなら「これにより」を使わない。

例：

```text
Before: さらに、導入コストを抑えることができます。
After: 導入コストも抑えやすくなります。
```

## 5. ぼかし・弱い断定

注意したい表現：

- 「〜と言えるでしょう」
- 「〜と考えられます」
- 「〜の可能性があります」
- 「〜が期待されます」
- 「〜が求められます」
- 「〜が必要不可欠です」

自然化の方向：

- 断定できるなら言い切る。
- 断定できないなら、なぜ保留するのかを書く。
- 「期待されます」ではなく、何が起きれば成功なのかを書く。

例：

```text
Before: 導入効果が期待されます。
After: 効果を見るなら、まずは作業時間と差し戻しの回数を追うのが現実的です。
```

## 6. 冗長な敬語・クッション

注意したい表現：

- 「〜させていただきます」
- 「〜につきましては」
- 「ご確認いただけますと幸いです」
- 「お忙しいところ恐れ入りますが」
- 「何卒よろしくお願い申し上げます」
- 「ご教示いただけますでしょうか」

自然化の方向：

- 顧客対応では丁寧さを残し、社内では短くする。
- 依頼内容、期限、相手の行動を明確にする。

例：

```text
Before: お忙しいところ恐れ入りますが、ご確認いただけますと幸いです。
After: お手すきの際にご確認ください。
```

社内なら：

```text
After: 確認お願いします。
```

## 7. 名詞化しすぎた表現

注意したい表現：

- 「〜の実施を行う」
- 「〜の検討を進める」
- 「〜の改善を図る」
- 「〜の推進に取り組む」
- 「〜の最大化を実現する」

自然化の方向：

- 動詞に戻す。
- 誰が何をするかを見えるようにする。

例：

```text
Before: 顧客満足度の向上を図ります。
After: 問い合わせ後の待ち時間を減らします。
```

## 8. 三分割・均等すぎる構成

注意したい表現：

- 「メリットは3つあります」
- 「第一に、第二に、第三に」
- 「Aだけでなく、Bも、さらにCも」
- 「課題、解決策、今後の展望」

自然化の方向：

- 本当に3つ必要かを見直す。
- 重要度に差をつける。
- 1つを深く書き、残りは短くする。

例：

```text
Before: メリットは3つあります。効率化、品質向上、コスト削減です。
After: 一番大きいのは、確認や差し戻しに取られていた時間が減ることです。品質やコストの話は、その後についてきます。
```

## 9. 技術記事で臭いやすい表現

注意したい表現：

- 「簡単に実装できます」
- 「わずか数ステップで」
- 「柔軟に対応できます」
- 「シームレスに連携します」
- 「強力な機能を提供します」

自然化の方向：

- 前提条件を書く。
- 制約を書く。
- どこで詰まりやすいかを書く。

例：

```text
Before: 簡単に実装できます。
After: 既存の認証まわりがシンプルなら、実装自体はそこまで重くありません。ただ、権限設計は先に決めておいたほうが安全です。
```

## 10. LP・広告で臭いやすい表現

注意したい表現：

- 「あなたのビジネスを次のステージへ」
- 「圧倒的な成果を実現」
- 「伴走支援」
- 「本質的な課題解決」
- 「選ばれる理由」
- 「最短で成果へ導く」

自然化の方向：

- 読者が今困っていることを言う。
- 何が変わるかを具体的にする。
- 誇張より、判断材料を出す。

例：

```text
Before: 本質的な課題解決を実現します。
After: 施策を増やす前に、どこで失注しているのかを一緒に見直します。
```
