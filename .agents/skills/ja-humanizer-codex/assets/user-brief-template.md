# ユーザーブリーフ・テンプレート

文章の自然化は、媒体と読者で結果が大きく変わります。必要に応じて、次の項目をユーザーに確認します。ただし、短い原稿や明らかな依頼では質問せず、合理的に仮定して進めます。

## 最小確認

```text
媒体:
読者:
目的:
トーン:
残したい表現:
避けたい表現:
出力形式:
```

## 詳細確認

```text
媒体:
- note / ブログ / X / LP / メール / 採用文 / 技術記事 / 社内文書 / その他

読者:
- 誰が読むか
- 前提知識はどの程度か
- 何に困っているか

目的:
- 読ませたい
- 申し込ませたい
- 理解させたい
- 返信させたい
- 採用応募につなげたい
- 誤解を減らしたい

トーン:
- 標準
- カジュアル
- 端的
- 信頼感
- 技術的
- セールス
- 丁寧
- 硬め

制約:
- 変えてはいけない数字・固有名詞
- 必ず残すキーワード
- 法務・広報確認済みの表現
- NG表現
- 文字数

出力:
- 改稿文のみ
- 改稿文 + 調整点
- Before/After
- 診断のみ
- 差分形式
```

## 迷ったときの仮定

ユーザーから追加情報がない場合は、次の仮定で進めます。

- 媒体: 一般的なWeb記事またはビジネス文書
- 読者: 日本語ネイティブの一般的なビジネス読者
- トーン: 丁寧すぎず、自然で読みやすい
- 出力: 改稿文 + 主な調整点3つ
- 制約: 意味、数字、固有名詞は保持

## 確認すべきケース

次の場合は、作業前に質問してください。

- 法的・医療・金融・契約文で、意味ズレのリスクが高い。
- 文体指定が曖昧で、カジュアル化すると問題になりそう。
- 読者が不明で、LP・採用・謝罪文など結果が大きく変わる。
- ユーザーが「人間の体験っぽく」と言っているが、実体験の根拠がない。
- 著名人や特定個人の文体をそのまま真似る依頼。

## ユーザーへの短い確認例

```text
媒体と読者でかなり文体が変わります。指定がなければ、一般的なビジネス読者向けに、丁寧すぎない自然な日本語で直します。
```

```text
この文章は顧客向けですか、社内向けですか。社内向けならかなり短くできます。
```

```text
実体験のような具体例は、こちらで作らず [要確認] として残します。
```
